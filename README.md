## Tools that check AI-assisted research

These open-source tools were evaluated with and without each tool in an open preprint, https://doi.org/10.5281/zenodo.23404947

- [verify-references](https://github.com/seun-john/verify-references) checks bibliographies against Crossref, OpenAlex, PubMed, CORE and DataCite to catch fabricated and mis-cited references.
- [citeproof](https://github.com/seun-john/citeproof) audits references and the claims they support, offline.
- [specguard](https://github.com/seun-john/specguard) tests whether AI-generated work followed the instructions it was given.
- [clean-output](https://github.com/seun-john/clean-output) keeps prompt scaffolding out of deliverables and flags prompt injection.
- [research-document-auditor](https://github.com/seun-john/research-document-auditor) audits theses, reports and manuscripts for citation, consistency and disclosure problems.
- [reviewtrace](https://github.com/seun-john/reviewtrace) traces reviewer feedback to the evidence that it was addressed in a revised document.
- [dataproof](https://github.com/seun-john/dataproof) recalculates the numbers in a report from the data behind them.
- [methodmatch](https://github.com/seun-john/methodmatch) checks that objectives, questions, variables, methods and findings are linked.
- [sourcepack](https://github.com/seun-john/sourcepack) bundles research sources with hashes and provenance into one verifiable archive.
- [privacygate](https://github.com/seun-john/privacygate) redacts personal data and secrets from text before it is shared with an AI service.
- [mcp-sentry](https://github.com/seun-john/mcp-sentry) audits MCP tool definitions and integration permissions.
- [agentreplay](https://github.com/seun-john/agentreplay) keeps tamper-evident, redacted logs of what an AI agent did.
- [correctionbank](https://github.com/seun-john/correctionbank) keeps a local record of corrections and decisions that must not drift.
- [releaseproof](https://github.com/seun-john/releaseproof) builds and smoke-tests a release archive before it is published.
- [litsearch-ii](https://github.com/seun-john/litsearch-ii) is a keyless literature-search MCP server.
